INSTRUÇÕES PARA EXUCUÇÃO DO PROJETO!! 

Como rodar os códigos: Pelo CLion:

Abra a pasta do projeto no CLion.

Abra o arquivo .cpp desejado (localizado na pasta src)

Clique no botão de Play ▶️ (no canto superior direito) para compilar e executar.

Como testar:
Digite a quantidade de elementos (ex: 5) e aperte Enter.
Digite os números da entrada (ex: 0 1 0 3 12) e aperte Enter.
O resultado ajustado será exibido diretamente na tela.
